                    COMMAND BERGUNA
═══════════════════════════════════════════════════════════════════

# Lihat status migration
php artisan migrate:status

# Reset database (HAPUS SEMUA DATA!)
php artisan migrate:fresh --seed

# Backup database (Windows)
mysqldump -u root -p123456 sipbar > backup_sipbar.sql

# Restore database
mysql -u root -p123456 sipbar < backup_sipbar.sql

# Cek koneksi database
php artisan db:show

# Clear cache
php artisan config:clear
php artisan route:clear
php artisan view:clear

                    TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

❌ Server error saat akses website
✅ SOLUSI: Clear cache & restart server
   php artisan config:clear
   php artisan serve

❌ Login error
✅ SOLUSI: Clear session
   php artisan cache:clear
   Clear browser cookies

❌ Data tidak muncul
✅ SOLUSI: Pastikan seeder sudah jalan
   php artisan migrate:fresh --seed

❌ MySQL connection refused
✅ SOLUSI: Start MySQL service
   net start mysql (atau mysql80)
