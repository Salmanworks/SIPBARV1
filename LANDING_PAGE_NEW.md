## 🎨 Design Philosophy

### **Natural, Not AI-Generated**

#### ❌ Avoided (AI-like patterns):
- Terlalu banyak "revolutionary", "cutting-edge", "next-generation"
- Kalimat panjang dan technical
- Terlalu banyak gradient dan animasi
- Layout yang terlalu "perfect"

#### ✅ Implemented (Human-friendly):
- Copy yang conversational dan to-the-point
- Fokus pada real benefits
- Visual previews yang konkret
- Layout yang breathable
- Micro-interactions yang subtle

## 🔧 Customization

### **Update Copy:**
Edit `resources/views/landing/index.blade.php`:
- Line 30-35: Hero headline
- Line 50-90: Quick features
- Line 200-250: Features section
- Line 280-320: How it works
- Line 350-400: Contact/CTA

### **Update Colors:**
Edit `tailwind.config.js`:
```js
colors: {
  primary: {...},
  secondary: {...}
}
```

### **Update Icons:**
Change icon names in blade file:
```blade
<x-icon name="your-icon" size="md" />
```
