═══════════════════════════════════════════════════════════════════
           🗄️ CARA MEMBUAT DATABASE SIPBAR - MYSQL
═══════════════════════════════════════════════════════════════════

Ada 3 cara untuk membuat database:

═══════════════════════════════════════════════════════════════════
CARA 1: Menggunakan Script Otomatis (TERMUDAH!)
═══════════════════════════════════════════════════════════════════

1. Klik 2x file: create_database.bat

2. Script akan otomatis:
   - Mencari MySQL di komputer Anda
   - Membuat database 'sipbar'
   - Menampilkan hasil

3. Jika berhasil, lanjut ke:
   php artisan migrate --seed

═══════════════════════════════════════════════════════════════════
CARA 2: Menggunakan phpMyAdmin (MUDAH!)
═══════════════════════════════════════════════════════════════════

1. Buka browser, akses:
   http://localhost/phpmyadmin

2. Login dengan:
   Username: root
   Password: 123456
   (atau sesuai password MySQL Anda)

3. Klik tab "SQL" di atas

4. Copy-paste SQL ini:
   ─────────────────────────────────────────────────────────────
   CREATE DATABASE sipbar 
   CHARACTER SET utf8mb4 
   COLLATE utf8mb4_unicode_ci;
   ─────────────────────────────────────────────────────────────

5. Klik tombol "Go"

6. Database 'sipbar' akan muncul di sidebar kiri

7. Lanjut ke terminal/cmd:
   php artisan migrate --seed

═══════════════════════════════════════════════════════════════════
CARA 3: Menggunakan MySQL Command Line
═══════════════════════════════════════════════════════════════════

1. Buka Command Prompt (CMD)

2. Masuk ke folder MySQL bin:
   
   XAMPP:
   cd C:\xampp\mysql\bin

   MySQL Standalone:
   cd "C:\Program Files\MySQL\MySQL Server 8.0\bin"

   WAMP:
   cd C:\wamp64\bin\mysql\mysql8.0.31\bin

3. Login ke MySQL:
   mysql -u root -p
   
   Masukkan password: 123456

4. Buat database:
   CREATE DATABASE sipbar CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

5. Verifikasi:
   SHOW DATABASES;
   
   (Anda akan lihat 'sipbar' di list)

6. Keluar:
   EXIT;

7. Kembali ke folder SIPBAR:
   cd C:\Users\Dell\SIPBAR

8. Jalankan migration:
   php artisan migrate --seed

═══════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

❌ ERROR: Access denied for user 'root'@'localhost'
✅ SOLUSI: Password MySQL salah
   - Buka file .env
   - Ubah DB_PASSWORD sesuai password MySQL Anda

❌ ERROR: Connection refused
✅ SOLUSI: MySQL service tidak running
   - Windows: net start mysql (atau mysql80)
   - XAMPP: Klik Start MySQL di XAMPP Control Panel

❌ ERROR: Unknown database 'sipbar'
✅ SOLUSI: Database belum dibuat
   - Ikuti salah satu cara di atas untuk buat database

❌ ERROR: Nothing to migrate
✅ SOLUSI: Migration sudah pernah jalan
   - Lihat status: php artisan migrate:status
   - Reset (HAPUS DATA!): php artisan migrate:fresh --seed

═══════════════════════════════════════════════════════════════════
KONFIGURASI .ENV (SUDAH DIUPDATE)
═══════════════════════════════════════════════════════════════════

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=sipbar
DB_USERNAME=root
DB_PASSWORD=123456

Jika password MySQL Anda berbeda, ubah DB_PASSWORD di file .env
