═══════════════════════════════════════════════════════════════════
SOLUSI 1: Jalankan Vite Dev Server (TERMUDAH & RECOMMENDED!)
═══════════════════════════════════════════════════════════════════

1. Buka 2 TERMINAL/Command Prompt terpisah

   TERMINAL 1 (Vite Dev Server):

   npm run dev

   Jangan tutup terminal ini selama development.

   TERMINAL 2 (Laravel Server):
   ─────────────────────────────────────────────────────
   php artisan serve

2. Buka browser:
   http://localhost:8000

3. SELESAI! Website akan muncul dengan sempurna ✅

CATATAN:
• Terminal 1 (npm run dev) HARUS tetap running
• Terminal 2 (php artisan serve) HARUS tetap running
• Jangan tutup kedua terminal selama development

═══════════════════════════════════════════════════════════════════
SOLUSI 2: Update Node.js (untuk build production)
═══════════════════════════════════════════════════════════════════

Versi Node.js Anda: v18.20.8 (TERLALU LAMA!)
Versi yang dibutuhkan: v20.x atau v22.x

Cara Update:
1. Download Node.js terbaru:
   https://nodejs.org/
   
   Pilih: LTS (Long Term Support) - v20.x atau v22.x

2. Install Node.js yang baru

3. Restart Command Prompt

4. Verifikasi:
   node --version
   (Harus menampilkan v20.x atau v22.x)

5. Install ulang packages:
   cd C:\Users\Dell\SIPBAR
   npm install

6. Build production:
   npm run build

7. Start server:
   php artisan serve

8. Buka browser:
   http://localhost:8000

═══════════════════════════════════════════════════════════════════
SOLUSI 3: Temporary Fix (Jika tidak bisa update Node.js)
═══════════════════════════════════════════════════════════════════

Downgrade Vite ke versi yang compatible dengan Node 18:

1. Edit file package.json:
   Ubah versi vite dari "^6.0.0" ke "^5.4.0"

2. Hapus node_modules & package-lock.json:
   Remove-Item node_modules -Recurse -Force
   Remove-Item package-lock.json -Force

3. Install ulang:
   npm install

4. Build:
   npm run build

5. Start server:
   php artisan serve

PENJELASAN
═══════════════════════════════════════════════════════════════════

Apa itu Vite?
→ Vite adalah build tool untuk compile CSS & JavaScript

Kenapa perlu npm run dev?
→ Agar CSS Tailwind & JavaScript ter-compile secara real-time

Apa bedanya npm run dev vs npm run build?
→ npm run dev  : Development mode (hot reload, debugging)
  npm run build: Production mode (optimized, minified)

Untuk development, SELALU gunakan: npm run dev
