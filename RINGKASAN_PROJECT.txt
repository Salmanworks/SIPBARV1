                    STRUKTUR DATABASE
═══════════════════════════════════════════════════════════════

6 Tabel Utama:
  1. users               → Data pengguna (5 fields aplikasi)
  2. kategoris           → Kategori barang (2 fields)
  3. barangs             → Data barang (7 fields)
  4. peminjamans         → Data peminjaman (8 fields)
  5. detail_peminjamans  → Detail barang per peminjaman (4 fields)
  6. dendas              → Data denda keterlambatan (5 fields)

Relasi:
  • users → peminjamans (1:N)
  • kategoris → barangs (1:N)
  • peminjamans → detail_peminjamans (1:N)
  • barangs → detail_peminjamans (1:N)
  • peminjamans → dendas (1:1)

Data Dummy (Seeder):
  • 5 users (1 admin, 1 petugas, 3 peminjam)
  • 8 kategori (Elektronik, Lab, Olahraga, dll)
  • 20+ barang sample
  • 10 peminjaman dengan berbagai status

                    CARA MENJALANKAN
═══════════════════════════════════════════════════════════════

QUICK START (5 Menit):

1. Install dependencies
   > composer install
   > npm install

2. Setup environment
   > copy .env.example .env
   > php artisan key:generate

3. Setup database
   > php artisan migrate --seed
   > php artisan storage:link

4. Build & run
   > npm run build
   > php artisan serve

5. Akses browser
   http://localhost:8000
